I served as a **Tutor and Marker** for [*Introduction to Computation (INFR08025)*](https://www.drps.ed.ac.uk/18-19/dpt/cxinfr08025.htm), a first-year undergraduate core course in the School of Informatics at the University of Edinburgh.

Responsibilities
======
- Led weekly tutorial sessions, supporting students with formative problem sets and core conceptual material  
- Provided continuous academic support and detailed feedback throughout the semester  
- Marked coursework and assessments, contributing to both formative and summative evaluation  
- Assisted students in developing problem decomposition, abstraction, and precise reasoning skills  

Course Overview
======
The course introduces foundational concepts of **programming, computation, and formal reasoning**, using a functional programming paradigm and formal models of computation.  
Teaching integrates programming practice with logical and mathematical reasoning, enabling students to specify, model, and solve small-scale problems at an abstract level.


Core Technical Topics
======

**1. Programming and Functional Concepts**
- Functional programming using **Haskell**  
- Functions and data structures, including lists and trees  
- Case analysis, recursion, and higher-order functions  
- Basic searching and sorting algorithms  
- Program documentation, testing, and debugging  

**2. Computation and Logic**
- Finite-state machines as models of computation  
  - Deterministic and non-deterministic automata  
  - Regular expressions and acceptors  
- Propositional logic  
  - Truth tables, satisfiability, and deduction  
- Use of sets, functions, and relations to model computational systems
