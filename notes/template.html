writing your first blog post

27 may 2026 — 3 min read

this is a template for a blog post. replace everything from here down with your own writing. keep it short if you want. no one said blog posts need to be long.

this whole site is just html files. to write a new post:

  1. copy this file into the posts/ folder with a descriptive name.
  2. change the <title> and <h1>.
  3. write your post between the <hr> tags.
  4. add a link to it in index.html under the blog section.

that’s it. no build step, no cms, no dependencies. markdown is nice but it requires a toolchain. plain html runs anywhere forever.

some things you can do without css: bold, italics, inline code, and blockquotes:
