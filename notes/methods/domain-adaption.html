domain adaption made simple

3 june 2026

making sure i stay sharp on my ml, i wanted to explore a topic which took ideas from gans (minmax modelling but being able to train models in a single backward pass) and made them easy to implement, good ml work which actually can be used. the general question domain adaption is trying to solve is: can we learn representations which are invariant with respect to shifts between domains? for example, take a set of images some are natural and other synthetic we wish to learn representations which are agnostic to where the image itself comes from. naturally one can extend these ideas to address fariness and systematic biases in any dataset, the world of imaging still gives fruits to neat ideas.

the architecture generally used in vanilla domain adaptation is the following. (1) we have a feature extractor $\theta_{f}$, then we use these features $\textbf{f}=\theta_{f}(\textbf{x})$ to feed them into (2) a classifier for the downstream task $\theta_{c}$ and (3) a domain discriminator $\theta_{d}$. the general idea is to move gradients of features in the opposite direction to "confuse" the discriminator, so features become domain invariant. this results in the discriminator struggling predict the domain from the features of (1).

but how do we do this in practice? and this is where, in contrast to gans, it can be trained end-to-end, simply by stitching both architectures together and using the same features for both models. for (2) the loss is $\mathcal{L}_{cls}(\theta_{f}, \theta_{c})$ and $\mathcal{L}_{disc}(\theta_{f}, \theta_{d})$ where $\mathcal{L}_{cls}(\cdot, \cdot)$ is the loss for label prediction, $\mathcal{L}_{disc}(\cdot, \cdot)$ is the loss for the domain classification.
