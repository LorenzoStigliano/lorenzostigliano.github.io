domain adaption made simple

3 june 2026

making sure i stay sharp on my ml, i wanted to explore a topic which took ideas from gans (minmax modelling but being able to train models in a single backward pass) and made them easy to implement, good ml work which actually can be used. the general question domain adaption is trying to solve is - can we learn representations which are invariant with respect to shifts between the domains? for example, take a set of images some are natural and other synthetic we wish to learn image representations which are agnostic where the image itself comes from. this naturally can be extend to debiasing and addressing fariness and systematic biases in any dataset, the world of imaging still gives fruits to neat ideas.
