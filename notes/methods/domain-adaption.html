Domain adaptation made simple

3 June 2026

To make sure I stay sharp on my ML, I wanted to explore a topic that took ideas from GANs (minmax modelling, but being able to train models in a single backward pass) and made them easy to implement: good ML work which can actually be used. The general question domain adaptation is trying to solve is: can we learn representations which are invariant with respect to shifts between domains? For example, take a set of images, some natural and others synthetic; we wish to learn representations which are agnostic to where the image itself comes from. Naturally, one can extend these ideas to address fairness and systematic biases in any dataset – the world of imaging still bears fruit for neat ideas. This idea was first introduced in 2015 in the paper “Unsupervised Domain Adaptation by Backpropagation”1.

The architecture generally used in vanilla domain adaptation is the following. (1) We have a feature extractor $\theta_{f}$, then we use these features $\textbf{f}=\theta_{f}(\textbf{x})$ to feed them into (2) a classifier for the downstream task, $\theta_{c}$, and (3) a domain discriminator, $\theta_{d}$. The general idea is to move gradients of features in the opposite direction to “confuse” the discriminator, so that features become domain invariant. This results in the discriminator struggling to predict the domain from the features of (1).

But how do we do this in practice? This is where, in contrast to GANs, it can be trained end-to-end, simply by stitching both architectures together and using the same features for both models. For (2) the loss is $\mathcal{L}_{c}(\theta_{f}, \theta_{c})$, and for (3) it is $\mathcal{L}_{d}(\theta_{f}, \theta_{d})$, where $\mathcal{L}_{c}(\cdot, \cdot)$ is the loss for label prediction and $\mathcal{L}_{d}(\cdot, \cdot)$ is the loss for the domain classification. Putting this together, we get a joint loss where we are both minimising the classification loss and maximising the discriminating loss via negation: $$ E = \sum_{i=1}^{n} \left[ \mathcal{L}_{c}(\theta_{f}, \theta_{c}; x_i) - \lambda \, \mathcal{L}_{d}(\theta_{f}, \theta_{d}; x_i) \right] $$ As a result, in order to find optimal parameters, they seek to optimise $\hat{\theta}_{f}, \hat{\theta}_{d}, \hat{\theta}_{c}$ via: $$ (\hat{\theta}_{f}, \hat{\theta}_{c}) = \arg\min_{\theta_{f},\, \theta_{c}} \; E(\theta_{f}, \theta_{c}, \hat{\theta}_{d}) $$ $$ \hat{\theta}_{d} = \arg\max_{\theta_{d}} \; E(\hat{\theta}_{f}, \hat{\theta}_{c}, \theta_{d}) $$ As a result, we can simply do gradient descent in the following fashion to update all parameters in the correct direction: $$ \theta_{f} \leftarrow \theta_{f} - \mu \left( \frac{\partial \mathcal{L}^i_c}{\partial \theta_{f}} - \lambda \frac{\partial \mathcal{L}^i_d}{\partial \theta_{f}} \right) $$ $$ \theta_{c} \leftarrow \theta_{c} - \mu \frac{\partial \mathcal{L}^i_c}{\partial \theta_{c}} $$ $$ \theta_{d} \leftarrow \theta_{d} - \mu \frac{\partial \mathcal{L}^i_d}{\partial \theta_{d}} $$ At the saddle point, the key thing to notice is that in $\theta_{f}$ the features are pushed to minimise the classification loss while maximising the domain loss, in turn creating domain invariant features. Also notice that $\max_{\theta_d} [ \mathcal{L}_{c} -\lambda \mathcal{L}_d] \equiv \max_{\theta_d} [-\lambda \mathcal{L}_d] \equiv \min_{\theta_d} \mathcal{L}_d$, so this is simply normal backpropagation (a sweet trick).

1 Ganin Y., Lempitsky V. Unsupervised Domain Adaptation by Backpropagation. In: International Conference on Machine Learning, 1 June 2015 (pp. 1180–1189). PMLR.
